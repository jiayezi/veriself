# 开发环境

`uv.lock` 是依赖的唯一事实来源。

```bash
uv sync --extra dev          # 建/更新 .venv（严格按 uv.lock）
uv run python -m pytest tests
uv run veriself demo
```

**不要用 `pip install`**（绕过锁文件、可能污染 `.venv`），**不要手改 `.venv`**。

Windows 终端另需设置编码，否则中文输出在管道里乱码（Git Bash / WSL 无需）：

```powershell
$env:PYTHONIOENCODING='utf-8'
```

## 本机特有约束（当前开发机器，Windows）

> 以下内容**只对当前开发环境成立**，换机器请忽略。

- **uv 缓存目录**：默认缓存在工作区外会 EPERM，需显式指定
  ```powershell
  $env:UV_CACHE_DIR='D:\code\work\.uv-cache'
  ```
- **没有 Docker**：`Dockerfile` / `docker-compose.yml` 可以写，但**无法在本机验证**，
  因此仓库不提供未经测试的容器化产物。
- **不要往工作区外写文件**：所有中间产物放 `data/`（已 gitignore）。
- **不要用 shell 重定向改写文件**（`Set-Content` / `>`）：会改变编码并损坏中文，
  详见 `AGENTS.md`。
